Как запустить

Windows, Linux, macOS — один скрипт

Скачай enternal.exe выше. Двойной клик — работает. Если антивирус ругается — добавь в исключения (это норма для неподписанных .exe).

  1. Скачай файл
  2. Положи в удобную папку
  3. Двойной клик по enternal.exe

Скачай бинарник, сделай исполняемым и запусти:

chmod +x enternal ./enternal

Или установи в систему:

sudo cp enternal /usr/local/bin/ enternal

Скачай .app, распакуй. Если macOS блокирует:

xattr -d com.apple.quarantine enternal.app

Или запусти из терминала:

./enternal.app/Contents/MacOS/enternal

Скачай enternal.py и установи зависимости:

pip install requests phonenumbers dnspython python-whois pytz python enternal.py

Работает везде, где есть Python 3.10+.

Частые вопросы

что спрашивают

Это легально?
Инструмент работает только с открытыми источниками — публичные API, поисковики, сайты. Ничего не взламывает, не пробивает закрытые базы. Использование в личных целях (проверить свою утечку, свой номер, свой домен) — законно. Против других без согласия — вопрос морали и местных законов.
Антивирус ругается
Это норма для неподписанных .exe из Python. PyInstaller-сборки часто ловят хеш-детекты. Добавь в исключения или используй исходник: python enternal.py.
Нужны API-ключи?
Большинство функций работает без ключей. Опционально: VirusTotal (бесплатный ключ), VK (сервисный ключ), Discord webhook (для отправки результатов). Прога сама попросит при первом входе.
Куда отправляются данные?
Никуда. Прога работает локально. Единственные внешние запросы — к публичным API (ip-api.com, GitHub и т.д.), плюс webhook если сам настроил. Никакой телеметрии, никакой аналитики.
Почему не показывает паспорт/адрес?
Эти данные в закрытых реестрах (МВД, банки, операторы). Доступ только через суд. OSINT работает с открытыми источниками. Всё что утекло в паблик — прога найдёт. Всё что не утекло — нет.
Как собрать .exe самому?
pip install pyinstaller pyinstaller --onefile --name="enternal" enternal.py
Готовый файл появится в dist/enternal.
